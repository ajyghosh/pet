# Feature requirements

## Navigation
Character Library > Create Character > (Create Manually | Create from Photo); My Custom Characters list supports preview, edit, duplicate, rename, delete, export and Add to Desktop.

## Manual creator
- Cute 3D miniature humans, consistent proportions, friendly faces and original/appropriately licensed assets.
- Face: shape, skin tone, eyes, brows, facial hair where supported.
- Hair: style and color.
- Clothing: shirts, jackets, dresses, jeans, saree, kurta, mundu, footwear (only where compatible with rigs).
- Accessories: glasses, hats, headphones, bags.
- Live preview with available angles, undo, reset and save. No paid service.

## Photo creator
- Upload JPG/PNG/WebP, crop, rotate, preview; optional local image-to-image conversion.
- Explicit opt-in before model download or any network/cloud processing.
- Show progress and error handling, offer manual fallback and allow edits to result.
- Clear temporary photos; user controls retained originals and deletion.
- No facial identity verification, face recognition database, or biometric matching.

## Runtime
- Custom characters share existing animation, reminder and interaction engines.
- Default height ~80 logical pixels, adjustable.
- Characters stand visually above Windows taskbar; macOS uses configurable Dock-area baseline, not an assumed identical taskbar.
- Limit active characters for performance; load assets lazily; inference is never resident during normal pet operation.
- Keep all existing data, collections, features, offline reminders and system tray.

## Accessibility
Keyboard-accessible creator controls, clear labels, high contrast UI, reduced-motion option, notification quiet hours.

## Legal
Original or properly licensed character assets; include source/attribution where required. Do not bundle copyrighted famous characters without distribution rights.
