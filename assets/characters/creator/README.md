# Character creator resources

Schema, sample metadata, and design documents for the heykup pets character creator.

- `schemas/character.schema.json`: implemented custom-character format.
- `examples/sample-character.json`: fixture used by native validation tests.
- `specs/FEATURE_REQUIREMENTS.md`, `instructions/IMPLEMENTATION_PLAN.md`, and `checklists/ACCEPTANCE_TESTS.md`: original design references, including future ideas.

The beta supports offline manual customization. Photo creation and external character-pack import are unavailable. See `../../../docs/CREATOR_STATUS.md` and `../../../docs/BETA_FIXES.md` for implementation status; design documents do not establish feature availability.
