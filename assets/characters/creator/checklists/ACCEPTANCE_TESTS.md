# Acceptance tests

- [ ] Existing app builds before and after integration.
- [ ] Character Library includes Create Character and My Custom Characters.
- [ ] Manual creator works fully offline without a dedicated GPU.
- [ ] Changing hair, face, outfit and accessories visibly updates a compatible character.
- [ ] Save, edit, duplicate, rename and delete persist across app restart.
- [ ] Custom character uses real compatible animations; missing animations are not falsely shown as completed.
- [ ] Add to Desktop walks above Windows taskbar or configured macOS Dock area.
- [ ] Reminders, multiple characters, tray and auto-start still work.
- [ ] Photo file selection validates type, dimensions and size; malformed input fails safely.
- [ ] Photo crop/preview and temporary-file deletion work.
- [ ] Photo conversion works on supported hardware or clearly falls back to manual creator.
- [ ] No photo leaves device without explicit informed consent.
- [ ] Local AI is unloaded after generation; normal pet mode does not load models.
- [ ] Imported/exported packs validate schema and reject unsafe paths.
- [ ] Tests cover Windows/macOS, multiple monitors, taskbar/Dock positioning, fullscreen and accessibility.
- [ ] Build logs, limitations, and actual measured resource use are reported.
